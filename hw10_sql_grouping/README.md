**Задание 1** — Получите статистику вида количество заказов в каждой категории в зависимости от населённого пункта (`JOIN` + `GROUP BY Location, Category`)

Ответ: Лидер по общему числу заказов — **Kyiv**, далее **Boryspil** и **Hostomel**.

**Задание 2** — В каком населённом пункте заказали больше всего игровых клавиатур? (`WHERE Description = 'Gaming Keyboard'` + `GROUP BY Location`)

Ответ: **Kyiv** (5 заказов), далее **Boryspil** и **Hostomel** — по 2 заказа в каждом.

**Задание 3** — В каких категориях чаще всего выполняют заказы люди с доходом более 2000 евро? (`WHERE Annual_Income > 2000` + `GROUP BY Category`)

Ответ: **Accessories** и **Electronics** (по 11 заказов каждая), далее **Office** (6 заказов), реже всего **Gaming** (4 заказа).
